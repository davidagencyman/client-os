# Client OS v6

This private repository is the durable operating memory for one AOTW client
engagement. The detailed session records are the primary history. Raw
transcripts are not required to remain here.

## Read first

1. AGENTS.md
2. context/client.md
3. context/engagement.md
4. status/current.md
5. status/actions.md
6. app/profile.json when App Export is enabled
7. the newest relevant session and workstream files

## Operating rule

Preserve important evidence in detailed sessions. Keep current status short.
Add capabilities and folders only when the work requires them. After a
successful source-processing run, update App Export and show the complete JSON
in chat.
